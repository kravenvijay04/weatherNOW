  <h2>🌟 Features</h2>
    <ul>
        <li>Get real-time weather updates</li>
        <li>Search weather by city</li>
        <li>Temperature, humidity, and wind speed information</li>
        <li>Supports multiple units (Celsius & Fahrenheit)</li>
    </ul>

  <h2>🛠️ Technologies Used</h2>
    <ul>
        <li>HTML, CSS, JavaScript</li>
        <li>Weather API (e.g., OpenWeatherMap, WeatherAPI)</li>
        <li>Fetch API for data requests</li>
    </ul>

  <h2>🚀 Installation</h2>
    <p>Follow these steps to set up the project:</p>
    <ol>
        <li>Clone the repository:
            <pre><code>git clone https://github.com/your-username/weather-app.git</code></pre>
        </li>
        <li>Navigate to the project directory:
            <pre><code>cd weather-app</code></pre>
        </li>
        <li>Open <code>index.html</code> in a browser.</li>
    </ol>

   <h2>📌 Usage</h2>
    <p>Enter the city name in the search bar and get real-time weather updates.</p>

  <h2>🔑 API Key Setup</h2>
    <p>To use the app, you need an API key from a weather service like OpenWeatherMap. Replace <code>YOUR_API_KEY</code> in the script file with your actual API key.</p>
